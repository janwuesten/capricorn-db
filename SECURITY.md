# Security Policy

## Supported Versions

The following versions will receive security updates. Make sure to keep your project up to date with a supported version.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| 0.2.x   | :white_check_mark: |

## Reporting a Vulnerability

To report a vulnerability use the "Report a vulnerability" button on the [GitHub security tab](https://github.com/janwuesten/capricorn-db/security).
